# WTDSight (моя модификация)

Форк/модификация оригинального проекта [dimas70800/WTDSight](https://github.com/dimas70800/WTDSight)
([оригинальный сайт](https://dimas70800.github.io/WTDSight/)). Все права на исходный код принадлежат автору оригинала.

Мои добавления:
- X-режим (клик-клик) + плавающий островок-индикатор
- Слои A/B с серой подложкой, слиянием и сохранением
- Сетка в игровой границе, цвет линий и перекрестия в своей панели
- Синхронизация углов/плотности штриховки с сеткой
